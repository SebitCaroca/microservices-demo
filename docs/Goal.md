# This file showcases what this project should do by functionality, and the reasoning behind the creation of this project.

---

## Functionality for the project (roughly):
- Create a wall of text, which anyone can read.
- An user can register, and post a new comment in the wall.
- Admins should be able to delete any comment they deem unfit for the wall.

---

## The importance of this project is to be able to do the following:

- Re-teach myself in the future how does a microservice project works.
- Learn how an IAM works in this project, and how to implement it. (Keycloak)
- Re-teach myself in the future how to deploy this using Docker, and then Kubernetes (minikube).
- Re-teach myself how I would theoretically deploy this on a server, such as Azure.
